Audio → MIDI Transcriber

Picks notes out of monophonic or moderately-polyphonic piano-style audio using Spotify's basic-pitch model. Transcription runs server-side and takes ~5-10s per minute of audio on Apple Silicon. Result is auto-loaded into the MIDI Renderer below — pick an instrument and render.

MIDI Renderer
Drop a MIDI file to start.

Renders the MIDI through the chosen digital instrument and loads it as the current source. Try the same MIDI through different instruments (piano → glass → bell → pad) for radically different chapter textures using the same underlying piece. Empty Target BPM keeps original tempo; type 72 to re-time for Ashley-style beds.

Piano Pulse Generator
4 bars @ 72 BPM = 13.33s of pure repeated C4.

Templates pre-fill all the fields. Ashley = 72 BPM single pulse for voiceover beds. Eastman = 136 BPM, low D, 8th-note hammered ostinato, 4 voices entering one bar at a time (additive accretion). Both can be further processed with any preset below; try EASTMAN's natural pair with high Drive + low Reverb.
