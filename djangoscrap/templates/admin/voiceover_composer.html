How to use · Ableton-style workflow

Tracks: voice on top, then beds underneath. Each track has a channel strip on the left (name · FX preset · volume · FX mix · solo/mute) and a draggable clip on the right.

Clips: drag clips left/right to set when they enter the timeline. The start time updates automatically. Voice always starts at 0 (your reference).

FX presets: each track has its own preset selector — Voice character (Ashley, Radio, Cathedral…) tuned for voice, plus the full Studio character library (P.LIVES, EASTMAN, HEARTBEAT…) usable on any track.

Sidechain: enabled on every bed by default. Beds dip automatically when you speak. Tune the depth/attack/release in the master bar at the bottom.

Sources panel: click ⌁ Generate / Library in the toolbar — slides up a panel where you pick existing library tracks or jump to a generator.

Project save/load: 💾 Save project stores all track state to your browser. ↻ Load restores it. ⬇ Export JSON downloads a portable snapshot.
